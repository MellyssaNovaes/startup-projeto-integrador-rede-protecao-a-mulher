# [Nome da Startup] — Continuidade da Jornada de Proteção à Mulher

Projeto Integrador — Startup do Zero
Ciência da Computação | UCB | 2026/2

## Sobre o projeto

Este repositório reúne toda a trajetória do grupo na disciplina Startup do Zero:
o problema investigado, o cliente estudado, as evidências levantadas, a proposta
de valor, o modelo de negócio, o MVP, a validação e as decisões tomadas ao longo
do semestre.

O projeto investiga a continuidade do atendimento a mulheres em situação de
violência doméstica ao longo da rede de proteção (segurança pública, saúde,
assistência social e Justiça), buscando entender em quais pontos essa jornada
pode ser interrompida e como uma solução tecnológica pode apoiar essa
continuidade.

## Como este repositório está organizado

```
├── docs/                      → uma seção do roteiro por arquivo (1 a 12)
├── anexos/                    → evidências: entrevistas, protótipo, declaração de uso de IA
├── backlog.md                 → backlog priorizado do projeto
└── README.md                  → este arquivo
```

Cada arquivo dentro de `docs/` corresponde exatamente a uma seção do roteiro de
entrega oficial da disciplina, na mesma ordem cobrada na avaliação. Isso permite
rastrear a coerência entre o que foi investigado, testado e decidido em cada
etapa.
