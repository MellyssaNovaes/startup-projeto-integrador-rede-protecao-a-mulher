# 1. Resumo Executivo

> Esta seção deve ser escrita **por último**, depois que todas as outras
> estiverem prontas — inclusive o Modelo de Negócio. Ela precisa caber em até
> uma página e apresentar o negócio inteiro de forma direta, sem repetir os
> textos completos das outras seções.

Preencher com no máximo um parágrafo curto (3–5 frases) para cada item abaixo:

**Problema**
[Qual é o problema real que o grupo identificou? Uma frase direta, sem
introdução longa.]

**Público**
[Quem é afetado por esse problema — o segmento/early adopter definido na
seção 3.]

**Solução**
[O que a startup propõe, em termos simples — a ideia central da seção 4,
sem repetir o Value Proposition Canvas inteiro.]

**Modelo de negócio**
[Como a startup pretende gerar receita e sustentar a operação — resumo de uma
frase do que estiver na seção 5.]

**Estágio atual**
[Em que ponto o projeto está agora: descoberta concluída, proposta de valor
validada, MVP em construção, etc.]

**Principal resultado de validação**
[O achado mais relevante até agora vindo das entrevistas, dados ou testes —
não é para citar todas as evidências, só a mais forte.]

---

*Checklist antes de considerar esta seção pronta:*
- [ ] Cabe em uma página impressa
- [ ] Não repete parágrafos inteiros de outras seções
- [ ] Uma pessoa que não conhece o projeto entende do que se trata só lendo isso
